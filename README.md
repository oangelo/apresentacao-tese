# Apresentação da defesa de tese (2014)

**Estudos de Sistemas Dinâmicos Não Lineares: Pêndulo Duplo, Batimentos Cardíacos e Coletivos de Animais**
Angelo Mondaini Calvão

Slides da defesa de doutorado, feitos em [reveal.js](https://revealjs.com). O deck é autocontido: o MathJax está vendorizado na pasta `MathJax/`, então as equações renderizam sem internet.

## Ver online

https://oangelo.github.io/apresentacao-tese/

## Rodar local

Basta abrir `index.html` no navegador, ou servir a pasta:

```bash
python3 -m http.server 8000
```

Navegação: setas para avançar, `Esc` para a visão geral dos slides, `S` para o modo apresentador.

## Conteúdo

- `index.html` — os slides (todo o conteúdo está aqui)
- `css/theme/angelo.css` — tema próprio
- `movies/` — vídeos das simulações (pêndulo duplo caótico/periódico, simulação de enxame)
- `img/` — figuras
- `MathJax/` — MathJax 2 completo, com fontes (136 MB, deliberadamente vendorizado)
